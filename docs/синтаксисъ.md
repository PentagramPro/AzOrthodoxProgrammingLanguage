# Языкъ «Азъ»: синтаксис

«Азъ» — православный язык программирования с церковнославянскими ключевыми словами.
Синтаксис взят из мема «православная IDE»: отступы и двоеточие как в Python, `#` для комментариев.
Компилятор переводит программу в C, а затем готовый C-компилятор (MSVC `cl`, `gcc`, `clang` или `tcc`) собирает настоящий `.exe` для Windows.

Файлы имеют расширение `.азъ` и хранятся в UTF-8.

## Первая программа

```азъ
глаго́ли «Здра́вствꙋй, мі́ре!»
```

```
az пусти здравствуй.азъ        # собрать и сразу запустить
az собери здравствуй.азъ       # получить здравствуй.exe
az си здравствуй.азъ           # показать сгенерированный C-код
```

## Правописание: старое и новое равно приемлемы

Перед сравнением компилятор приводит каждое слово к простому виду:

- убираются ударения, придыхания, титла и прочие надстрочные знаки (`є҆́сть` = `есть`);
- древние буквы заменяются гражданскими: `ѣ→е`, `і ї ѵ→и`, `ѳ→ф`, `ѡ ѻ→о`, `ꙋ ѹ оу→у`, `ѧ ꙗ→я`, `ѕ→з`, `ѯ→кс`, `ѱ→пс`, `ѿ→от`, `й→и`;
- конечный `ъ` отбрасывается, регистр не важен.

Поэтому `функці́ѧ`, `функція` и `функция` — одно и то же слово. Это касается и имён переменных: `Благовѣ́стъ` и `благовест` — одно имя.

## Ключевые слова

| Значение | Слова (любое из них) | Как в Python |
|---|---|---|
| объявить функцию | `функція`, `дѣяніе` | `def` |
| вернуть значение | `возврати`, `возвратити`, `верни` | `return` |
| условие | `аще` … `иначе аще` … `иначе` / `инако` | `if` / `elif` / `else` |
| цикл с условием | `покуда`, `доколѣ` | `while` |
| цикл обхода | `для` / `всяко` *имя* `во` *что* | `for … in` |
| выйти из цикла | `прерви`, `довольно` | `break` |
| следующий проход | `продолжи`, `паки` | `continue` |
| вывести на экран | `глаголи`, `рцы` | `print` |
| присвоить | `есть`, `бысть`, `буди`, `=` | `=` |
| равенство | `есть` (внутри выражения) | `==` |
| неравенство | `не есть` | `!=` |
| больше / меньше | `вяще`, `болѣе`, `больше` / `менѣе`, `меньше` | `>` / `<` |
| и, или, не | `и`, `або` / `или` / `либо`, `не` | `and`, `or`, `not` |
| истина | `истина`, `правда`, `Аминь` | `True` |
| ложь | `ложь`, `кривда` | `False` |
| пусто | `безвѣстно`, `безвѣстна`, `ничтоже` | `None` |
| взять элемент | `ѿ` (`от`) | `[ ]` |
| объявить переменные | `суть` (несколько), `же` (одну) | — |
| аварийный выход | `анаѳема` *сообщение* | `raise` + `exit(1)` |

Поскольку `и` — это союз «и», назвать переменную `и` нельзя. Используйте `к`, `ч`, `кругъ` и т. п.

## Числа: арабские и кириллические

Числа можно писать арабскими цифрами (`42`, `3.14`) или кириллической цифирью под титлом:

| Запись | Значение |
|---|---|
| `а҃` | 1 |
| `і҃` | 10 |
| `в҃і` | 12 |
| `к҃є` | 25 |
| `ҁ҃` / `ч҃` | 90 |
| `҂вк҃ѕ` | 2026 |

Титло (`҃`, U+0483) обязательно, иначе слово будет прочитано как имя переменной. Знак `҂` перед буквой означает тысячи.
Обратно: `кириллицею(2026)` даёт слово `«҂вк҃ѕ»`.

**Нуля в кириллической цифири нет, поэтому счёт в свитках ведётся с единицы**: первый элемент — `свитокъ ѿ а҃`.

## Значения и их виды

| Вид | Пример | Пустое значение при объявлении |
|---|---|---|
| цѣлое | `7`, `з҃` | `0` |
| дробное | `2.5` | `0.0` |
| слово (строка) | `«Миръ всѣмъ»`, `"текст"` | `«»` |
| истинность | `истина`, `ложь` | `ложь` |
| свитокъ (список) | `[1, 2, 3]` | `[]` |
| словникъ (словарь) | `{«а»: 1, 2: «два»}` | `{}` |
| безвѣстно | `безвѣстно` | — |

Типизация динамическая. Объявлять переменные не обязательно, но можно, как в меме:

```азъ
а, б, в сꙋ́ть цѣ̑лыѧ          # все три равны 0
славосло́въ же словни́къ       # пустой словарь
```

Названия видов после `суть` или `же`: `цѣлое/цѣлыя`, `дробное`, `слово/словеса/строка`, `словникъ/словарь`, `свитокъ/списокъ`, `истинность`.

В строках работают `\n`, `\t`, `\\`, `\"`. Строки в ёлочках `«…»` экранировать не нужно.

## Присваивание и указание

```азъ
а є҆́сть 5
а є҆́сть а + 1
а += 1                         # то же, что а есть а + 1

свитокъ є҆́сть [«а», «б»]
свитокъ ѿ а҃ є҆́сть «альфа»    # заменить первый элемент
свитокъ ѿ г҃ є҆́сть «в»        # индекс длина+1 добавляет элемент в конец
глаго́ли свитокъ[2]            # квадратные скобки тоже работают

словникъ ѿ «ключъ» є҆́сть 42
глаго́ли словникъ ѿ «нѣтъ»     # безвѣстно, ошибки нет
```

`есть` в начале предложения (после имени или `X ѿ Y`) означает присваивание, а внутри выражения — сравнение:

```азъ
а҆́ще покаѧ́нїе є҆́сть ло́жь а҆́бо ѵ҆поста́сь не є҆́сть безвѣ́стна:
    ...
```

## Сравнения

```азъ
а҆́ще х вѧ́щше 10:        # х > 10
а҆́ще х не вѧ́щше 10:     # х <= 10
а҆́ще х менѣ́е 10:        # х < 10
а҆́ще х не менѣ́е 10:     # х >= 10
а҆́ще х є҆́сть вѧ́щше у:   # «есть» перед сравнением можно ставить
а҆́ще х не є҆́сть вѧ́щше у:  # х <= у
```

Работают и обычные символы `== != < > <= >=`.

## Арифметика

`+ - * / // %`. Сложение со словом склеивает строки: `«Лѣто » + 2026`.
Деление `/` даёт целое, если делится нацело, иначе дробное. `//` — деление с округлением вниз.
Слово, умноженное на число, повторяется: `«Аллилꙋ́їа » * 3`.

## Условия и циклы

```азъ
а҆́ще х вѧ́щше 0:
    глаго́ли «положительно»
и҆на́че а҆́ще х є҆́сть 0:
    глаго́ли «нуль, егоже въ цыфири несть»
и҆на́че:
    глаго́ли «отрицательно»

поку́да н вѧ́щше 0:
    н є҆́сть н - 1

для ч во [1, 2, 3]:      глаго́ли ч
для ч во 5:              глаго́ли ч         # 1, 2, 3, 4, 5
для ч во чреда̀(10, 1):   глаго́ли ч         # обратный счёт
для ключъ во словникъ:   глаго́ли ключъ
для буква во «Азъ»:      глаго́ли буква
```

Короткое тело можно писать на той же строке после двоеточия.

## Функции

```азъ
функці́ѧ Благовѣ́стъ (ѵ҆поста́сь, покаѧ́нїе є҆́сть ло́жь):
    ...
    возвратѝ А҆ми́нь

Благовѣ́стъ(а҃)
Благовѣ́стъ(безвѣ́стно, и҆сти́на)
```

- Значение по умолчанию задаётся через `есть` или `=` и может быть только простым значением (числом, словом, истиной/ложью, `безвѣстно`).
- Функции объявляются только на верхнем уровне. Вызывать их можно до объявления; рекурсия разрешена.
- Переменные, которым что-либо присвоено в главном теле программы, **общие** (глобальные). Остальные переменные внутри функции местные.
- Функция без `возврати` возвращает `безвѣстно`.
- `возврати` в главном теле завершает программу; целое число становится кодом выхода.

Запись через точку `х.дѣйство(…)` означает то же, что `дѣйство(х, …)`. Например, `славосло́въ.сочта́ти()` = `сочтати(славосло́въ)`.

## Встроенные действия

| Действие | Что делает |
|---|---|
| `длина(х)`, `мѣра(х)`, `сочти(х)`, `сочтати(х)` | длина слова, свитка или словника |
| `приложи(свитокъ, х)` | добавить в конец |
| `изъми(свитокъ)` | убрать и вернуть последний элемент |
| `ключи(словникъ)` | свиток ключей |
| `имать(что, х)` | есть ли ключ, элемент или подстрока |
| `чреда(а, б)` / `чреда(н)` | свиток чисел от а до б включительно / от 1 до н |
| `число(х)`, `дробь(х)`, `слово(х)` | преобразование вида |
| `видъ(х)` | название вида: «цѣлое», «слово»… |
| `корень(х)`, `мѣрило(х)` | квадратный корень, модуль числа |
| `жребій(а, б)` | случайное целое от а до б |
| `почій(мс)` | пауза в миллисекундах |
| `время()` | миллисекунды с начала работы |
| `раздѣли(слово, раздѣлитель)` | разбить строку (без разделителя — по пробелам) |
| `совокупи(свитокъ, раздѣлитель)` | склеить свиток в строку |
| `внемли()` / `внемли(«вопросъ»)` | прочесть строку с клавиатуры |
| `кириллицею(н)` | число кириллической цифирью: `кириллицею(12)` → `в҃і` |

## Ошибки

Ошибка компиляции называется **прегрѣшеніе**. Она выводится в формате `файлъ:строка:столбецъ: прегрѣшеніе: …`, и IDE подсвечивает это место.
Ошибка во время выполнения называется **анаѳема**: программа печатает номер строки и описание и завершается с кодом 1.
Объявить анафему можно и самому: `анаѳе́ма «Не прели́стисѧ»`.

## Порядок вычисления

Выражения вычисляются слева направо. У `глаголи` и вызовов функций сначала вычисляются все аргументы, и только потом выполняется само действие.
Например, `глаголи свитокъ, изъми(свитокъ)` напечатает свиток уже после изъятия. В прототипе на C было иначе: там каждый элемент печатался сразу.

## Как это устроено

```
файлъ.азъ ──лексеръ/парсеръ (src/Az.Compiler)──► C# 5 + рантаймъ AzRuntime.cs
          ──► csc.exe изъ .NET Framework 4.x (встроенъ въ Windows) ──► файлъ.exe
```

- Транслятор и IDE написаны на C# (.NET 10). Сами программы на «Азѣ» компилируются встроенным в Windows `csc.exe` (`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319`). Visual Studio и .NET SDK для этого не нужны. Другой `csc.exe` можно указать через переменную `AZ_CSC`.
- Получается маленький `.exe` (десятки килобайт), который запускается на любой Windows 10/11 без установки чего-либо.
- Память освобождает сборщик мусора .NET. Программа работает в потоке со стеком 256 МБ, поэтому рекурсия может быть глубокой. Бесконечная рекурсия заканчивается анафемой, а не падением процесса.
- В консоли текст выводится через `WriteConsoleW`, а при перенаправлении — в UTF-8. Кириллица читается правильно.
- Скомпилированные программы кешируются по хешу исходника в `%TEMP%\az_build`, поэтому повторная сборка мгновенна.
- Сгенерированный C# можно посмотреть командой `az си файлъ.азъ` или в IDE через меню «Кодъ → Показати C#-кодъ». Имена в нём остаются кириллическими: функции получают префикс `Ф_`, общие переменные — `Г_`.
