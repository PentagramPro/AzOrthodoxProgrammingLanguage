О руководстве

Это руководство описывает язык А҆́зъ версии {{VERSION}}: его письмо, лексику, виды значений, управляющие конструкции, функции и встроенные действия, а также инструменты — транслятор az и среду разработки «Скрипторїй». Первые главы читаются по порядку, как учебник. Последние главы и приложения служат справочником.

Язык родился из шуточной картинки, на которой была изображена «православная среда разработки». Шутка оказалась удачной, и язык получился настоящим: каждая программа из этого руководства компилируется в обычный исполняемый файл Windows. Более того, все примеры, рядом с которыми напечатан их вывод, действительно были собраны и запущены при вёрстке этого документа. Вывод взят из настоящего запуска, а не набран вручную.

Оглавле́нїе

Глава 1 а҃Введение

✦ ✦ ✦

А҆́зъ — компилируемый язык программирования с церковнославянскими ключевыми словами. По устройству он похож на Python: блоки выделяются отступами, после заголовка блока ставится двоеточие, типы значений определяются во время выполнения. По облику это язык богослужебных книг: а҆́ще вместо if, поку́да вместо while, глаго́ли вместо print и числа, записанные буквами под титлом.

Название языка — первая буква кириллической азбуки, а҆́зъ. С неё начинается всякое учение, а файлы с исходным текстом носят расширение .азъ.

1.1Как устроен язык

Программа на «Азѣ» не интерпретируется. Транслятор az разбирает исходный текст, строит дерево программы и порождает по нему текст на языке C#. Затем компилятор csc.exe, который входит в состав .NET Framework и есть в каждой Windows 10 и 11, превращает этот текст в исполняемый файл.

Получившийся .exe ни от чего не зависит: его можно переписать на другой компьютер с Windows и запустить без установки «Аза». Память в программах освобождает сборщик мусора .NET, а ошибки выполнения сообщаются понятным текстом с номером строки исходника.

1.2Состав и установка

Составная частьНазначение

Для сборки инструментов нужен .NET 10 SDK. Для сборки программ на «Азѣ» ничего, кроме Windows, не нужно. Чтобы собрать инструменты, запустите в корне проекта:

> собрать.cmd
Собрано въ C:\…\bin. Слава Богу!

После этого в папке bin появятся az.exe и Skriptorij.exe. Сценарии az.cmd и скрипторий.cmd в корне проекта при первом запуске сами вызывают сборку.

Компилятор csc.exe ищется в %WINDIR%\Microsoft.NET\Framework64\v4.0.30319. Если он лежит в другом месте, укажите путь в переменной окружения AZ_CSC.

Глава 2 в҃Первая программа

✦ ✦ ✦

По доброй традиции первая программа на всяком языке приветствует мир. На «Азѣ» она состоит из одной строки.

глаго́ли «Здра́вствꙋй, мі́ре!»

Слово глаго́ли («говори») выводит на экран значения, перечисленные через запятую, и переводит строку. Текст в ёлочках «…» — это слово, то есть строка.

2.1Запуск из командной строки

Сохраните программу в файл здравствꙋй_мїре.азъ в кодировке UTF-8 и выполните:

> az пусти здравствꙋй_мїре.азъ      # собрать во временную папку и сразу запустить
Здра́вствꙋй, мі́ре!

> az собери здравствꙋй_мїре.азъ     # положить здравствꙋй_мїре.exe рядом с исходником
Собрано: …\здравствꙋй_мїре.exe  (csc изъ .NET Framework). Слава Богу!

> здравствꙋй_мїре.exe
Здра́вствꙋй, мі́ре!

2.2Запуск из «Скрипторїя»

В среде разработки откройте файл в древе проекта и нажмите Shift+F10 или кнопку ▶ Пꙋсти́ти. Вывод программы появится в нижней панели «Исход». Если программа задаёт вопросы через внемлѝ(), заранее впишите ответы в поле «Ввод» справа, по одному в строке.

2.3Программа посложнее

Вот программа, которая спрашивает имя, отвечает на него и считает до трёх. Мы разберём каждую её строку в следующих главах, а пока просто прочтите её — она читается почти как обычный текст.

#  Спрашиваемъ имя и приветствуемъ
и҆́мѧ є҆́сть внемлѝ(«Ка́кѡ и҆́мѧ твоѐ? »)
а҆́ще и҆́мѧ є҆́сть «»:
    и҆́мѧ є҆́сть «ра́бъ Бж҃їй»
глаго́ли «Ми́ръ ти,», и҆́мѧ + «!»

для ч во 3:
    глаго́ли «Покло́нъ», кириллицею(ч)
глаго́ли «А҆ми́нь.»

Здесь встречаются почти все основные понятия языка:

  • присваивание — и҆́мѧ є҆́сть …: переменная и҆́мѧ получает значение;
  • встроенное действие внемлѝ(…) — печатает вопрос и читает строку с клавиатуры;
  • условие а҆́ще … : и его тело, сдвинутое отступом на четыре пробела;
  • цикл для ч во 3:, который выполняет тело для ч = 1, 2, 3;
  • кириллическая цифирь: кириллицею(ч) записывает число буквами под титлом.

Глава 3 г҃Письмо и правописание

✦ ✦ ✦

Программы на «Азѐ» можно писать и церковнославянской орфографией с ударениями и титлами, и обычной гражданской азбукой. Транслятор понимает и то и другое, потому что перед сравнением слов приводит каждое из них к простому виду.

3.1Нормализация слов

Каждое ключевое слово и каждое имя переменной проходит через три преобразования:

  1. снимаются все надстрочные знаки: ударения (оксия, вария, камора), придыхания, титла;
  2. древние буквы заменяются гражданскими по таблице ниже;
  3. отбрасывается конечный ъ, и все буквы приводятся к строчным.
БукваЧитается какБукваЧитается какБукваЧитается как
ѣеі ї ѵиѳф
ѡ ѻоꙋ ѹ оу ѫуѧ ꙗя
єеѕ ꙁзѯкс
ѱпсѿотй ёи, е
 Таблица 3.1. Соответствие древних и гражданских букв при сравнении слов

Поэтому функці́ѧ, функція и функция — одно и то же ключевое слово, а Благовѣ́стъ и благовест — одно и то же имя. Следующие три строки делают одно и то же:

а҆́ще и҆сти́на: глаго́ли «по-церко́вному»
аще истина: глаголи "по-граждански"
АЩЕ ИСТИНА: ГЛАГОЛИ «и даже прописными»
Внимание

Нормализация касается только ключевых слов и имён. Строки в кавычках и ёлочках сохраняются в точности как написаны, со всеми ударениями.

3.2Как набирать церковнославянский текст

На обычной клавиатуре нет букв ѣ ѿ ѳ ꙋ и надстрочных знаков. Есть три способа их набрать.

  • Панель «Буквы» в «Скрипторїи». Она находится над редактором: щелчок по кнопке вставляет букву или надстрочный знак в позицию курсора. Надстрочный знак ставится над буквой, стоящей перед курсором.
  • Гражданская азбука. Писать без древних букв вполне законно: аще ничем не хуже а҆́ще.
  • Раскладка или шрифт с поддержкой Unicode, например раскладки Slavonic Computing Initiative.
ЗнакНазваниеUnicodeГде нужен
◌҃титлоU+0483числа (а҃), сокращения (Бг҃ъ)
҂знак тысячU+0482числа от 1000 (҂вк҃ѕ)
◌́ ◌̀ ◌̑оксия, вария, камораU+0301 0300 0311ударения — только для красоты
◌҆придыхание (звательце)U+0486над начальной гласной — только для красоты

3.3Имена

Имя переменной или функции — непрерывная последовательность букв (кириллических или латинских), цифр, знака подчёркивания и надстрочных знаков, начинающаяся с буквы. Регистр не различается, конечный ъ не учитывается: Ро́дъ, род и РОД — одно имя.

Внимание

Ключевые слова нельзя использовать как имена. Особенно легко споткнуться о союз и и о слово во: назвать счётчик цикла і нельзя, потому что і после нормализации превращается в и. Берите к, ч, кру́гъ. А вот а, б, в — обычные имена, как на знаменитом меме.

Глава 4 д҃Лексика

✦ ✦ ✦

Программа состоит из строк. Каждая строка — одно предложение: присваивание, вызов, вывод или заголовок блока. Предложение заканчивается вместе со строкой, точка с запятой не нужна. Внутри круглых, квадратных и фигурных скобок выражение можно переносить на следующие строки.

4.1Комментарии

Всё, что следует за знаком # до конца строки, — комментарий; транслятор его не читает.

# Глаго́лѧ словеса̀ бл҃га̑ѧ — это комментарий
х є҆́сть 5   # и это тоже

4.2Слова (строки)

Строку можно заключить в ёлочки «…» или в прямые кавычки "…". Внутри ёлочек прямые кавычки не нужно экранировать, и наоборот. Строка должна закончиться на той же строке исходника.

ЗаписьЗначение
\nперевод строки
\tтабуляция
\\обратная косая черта
\", \«, \»кавычка или ёлочка внутри строки

Кроме слов, в языке есть привычные знаки: арифметические + - * / // %, сравнения == != < > <= >=, присваивания = += -=, а также скобки ( ) [ ] { }, запятая, двоеточие и точка.

Глава 6 ѕ҃Переменные

✦ ✦ ✦

Переменная появляется в тот момент, когда ей впервые присваивают значение. Присваивание записывается словом є҆́сть в начале предложения: «а есть пять». Вместо него можно писать бы́сть, бꙋ́ди или знак =.

а є҆́сть 5
б бы́сть а * 2
в = б - 1
а += 10         # то же, что «а є҆́сть а + 10»
в -= 1
глаго́ли а, б, в

Переменные, которым что-либо присваивается в главном теле программы (вне функций), — общие: они видны и в главном теле, и внутри всех функций. Переменные, которые появляются только внутри функции, — местные: они создаются заново при каждом вызове и не видны снаружи.

глаго́ли «Всегѡ̀ покло́нѡвъ:», счётъ
Внимание

Если внутри функции присвоить значение имени, которое уже используется как общее, изменится именно общая переменная. Давайте местным переменным имена, не совпадающие с общими.

Глава 7 з҃Выражения

✦ ✦ ✦

Выражение вычисляет значение. Выражения строятся из значений, имён, вызовов и знаков и вычисляются слева направо с учётом старшинства действий.

7.1Арифметика

ЗнакДействиеОсобенности
+сложениесо словом — склеивание: «Лѣ́то » + 2026
-вычитание, смена знака
*умножениеслово × число — повторение: «ѡ҆ » * 3
/делениецелое, если делится нацело, иначе дробное
//целочисленное делениес округлением вниз
%остатокзнак остатка совпадает со знаком делителя
 
глаго́ли 7 / 2, 8 / 2, 7 // 2, -7 // 2, 7 % 3, -7 % 3
глаго́ли «Лѣ́то » + 2026, «Аллилꙋ́їа » * 3
глаго́ли [1, 2] + [3], корень(16), мерило(-5)
Внимание

Деление на нуль приводит к анафеме — аварийному завершению программы (глава 12): «дѣленіе на нуль, егоже несть въ кириллической цыфири».

7.2Сравнения

Сравнивать можно словами или знаками. Слово є҆́сть внутри выражения означает равенство, не обращает сравнение. Перед вѧ́щше и менѣ́е слово є҆́сть можно ставить или опускать — смысл не меняется.

СловамиЗнакомСмысл
х є҆́сть ух == уравно
х не є҆́сть ух != уне равно
х вѧ́щше у · х є҆́сть вѧ́щше ух > убольше
х менѣ́е ух < уменьше
х не вѧ́щше у · х не є҆́сть вѧ́щше ух <= уне больше
х не менѣ́е ух >= уне меньше

Числа сравниваются по величине (целое 2 равно дробному 2.0), слова — по алфавиту, свитки равны, если поэлементно равны их элементы.

7.3Логика

Союзы и, а҆́бо (или и҆лѝ, ли́бо) и частица не соединяют условия. Результат всегда и҆сти́на или ло́жь.

лѣ́то є҆́сть 2026
посто́мъ є҆́сть ло́жь
глаго́ли лѣ́то вѧ́щше 2000 и не посто́мъ
глаго́ли лѣ́то менѣ́е 1000 а҆́бо посто́мъ

Глава 8 и҃Управляющие конструкции

✦ ✦ ✦

Блок — это заголовок, оканчивающийся двоеточием, и тело: одна или несколько строк, сдвинутых вправо на одинаковый отступ (принято четыре пробела). Тело заканчивается там, где отступ возвращается назад.

8.1Условие: а҆́ще — и҆на́че

Условие проверяет выражение и выполняет тело, только если оно истинно. Ветвей и҆на́че а҆́ще может быть сколько угодно; последняя ветвь и҆на́че выполняется, когда не подошла ни одна из прежних.

для мѣ́сѧцъ во [1, 4, 7, 12]:
    а҆́ще мѣ́сѧцъ не вѧ́щше 2 а҆́бо мѣ́сѧцъ є҆́сть 12:
        глаго́ли мѣ́сѧцъ, «— зима̀»
    и҆на́че а҆́ще мѣ́сѧцъ не вѧ́щше 5:
        глаго́ли мѣ́сѧцъ, «— весна̀»
    и҆на́че а҆́ще мѣ́сѧцъ не вѧ́щше 8:
        глаго́ли мѣ́сѧцъ, «— лѣ́то»
    и҆на́че:
        глаго́ли мѣ́сѧцъ, «— ѻ҆́сень»

8.2Цикл с условием: поку́да

Тело цикла поку́да повторяется, пока условие истинно. Условие проверяется перед каждым проходом, так что тело может не выполниться ни разу.

ꙋда́ры є҆́сть 1
поку́да ꙋда́ры не вѧ́щше 4:
    глаго́ли «Бо́мъ!» * ꙋда́ры
    ꙋда́ры += 1

8.3Обход: для … во

Цикл для по очереди присваивает переменной каждый элемент последовательности и выполняет тело. Что считается элементами, зависит от вида значения после во:

После воЭлементы
свитокего элементы по порядку
словникего ключи в порядке добавления
словобуквы (буква вместе с её ударениями и титлами — одна)
целое число нчисла 1, 2, …, н
чреда̀(а, б)числа от а до б включительно, в том числе по убыванию
 
для ч во 3:                 глаго́ли «№», ч
для ч во чреда̀(10, 8):      глаго́ли «ѿсчётъ», ч
для бꙋ́ква во «А҆́зъ»:        глаго́ли «[» + бꙋ́ква + «]»
для дн҃ь во {«понедѣ́льникъ»: 1, «вто́рникъ»: 2}: глаго́ли дн҃ь

8.4прерви и продолжи

прерви немедленно выходит из ближайшего цикла, продолжи переходит к следующему проходу. Вне цикла оба слова — прегрешение.

для ч во чреда̀(1, 100):
    а҆́ще ч % 2 є҆́сть 0:
        продолжи                 # чётныя пропꙋска́емъ
    а҆́ще ч % 7 є҆́сть 0:
        глаго́ли «Пе́рвое нечётное кра́тное семѝ:», ч
        прерви

8.5Короткая запись

Если тело блока — одно простое предложение, его можно написать в той же строке после двоеточия:

а҆́ще х вѧ́щше 0: глаго́ли «положи́тельно»
для ч во 3: глаго́ли ч

Глава 9 ѳ҃Функции

✦ ✦ ✦

Функция — именованный блок, который можно вызывать с разными доводами (аргументами). Функция объявляется словом функці́ѧ (или дѣѧ́нїе), возвращает значение словом возвратѝ и вызывается по имени со скобками.

функці́ѧ Пло́щадь (ширина̀, высота̀):
    возвратѝ ширина̀ * высота̀

глаго́ли «Пло́щадь хра́ма:», Пло́щадь(12, 30), «кв. саже́ней»

Имя функции по обычаю пишут с прописной буквы. «Скрипторїй» и это руководство выделяют первую букву киноварью, как буквицу в рукописи.

9.1Доводы по умолчанию

У довода может быть значение по умолчанию, оно указывается через є҆́сть или =. Такие доводы можно не передавать при вызове. Значением по умолчанию может быть только простое значение: число, слово, и҆сти́на, ло́жь или безвѣ́стно. Вот функция с того самого мема — теперь она действительно работает:

функці́ѧ Благовѣ́стъ (ѵ҆поста́сь, покаѧ́нїе є҆́сть ло́жь):
    а, б, в сꙋ́ть цѣ̑лыѧ
    славосло́въ же словни́къ
    славосло́въ ѿ а҃ є҆́сть «Не бо́йсѧ, дщи сїѡ́нѧ»
    славосло́въ ѿ в҃ є҆́сть «Прїи́де же і҆и҃съ»
    славосло́въ ѿ г҃ є҆́сть «И҆зы́де же сло́во сїѐ»

    а҆́ще покаѧ́нїе є҆́сть ло́жь а҆́бо ѵ҆поста́сь не є҆́сть безвѣ́стна:
        а҆́ще славосло́въ ѿ ѵ҆поста́сь:
            глаго́ли славосло́въ ѿ ѵ҆поста́сь
    и҆на́ко:
        а є҆́сть славосло́въ.сочта́ти()
        б є҆́сть а҃
        поку́да б не є҆́сть вѧ́щше а:
            глаго́ли кириллицею(б) + «.», славосло́въ ѿ б
            б є҆́сть б + а҃
    возвратѝ А҆ми́нь

Благовѣ́стъ(в҃)
Благовѣ́стъ(безвѣ́стно, и҆сти́на)

9.2Возврат значения

возвратѝ немедленно завершает функцию и передаёт значение вызвавшему. Функция, дошедшая до конца без возвратѝ, возвращает безвѣ́стно. Функции объявляются только в главном теле программы (не внутри других функций) и могут вызываться раньше, чем объявлены.

9.3Рекурсия

Функция может вызывать саму себя. Программа выполняется в потоке с большим стеком, поэтому глубина рекурсии в тысячи вызовов не страшна. Бесконечная рекурсия завершается анафемой, а не молчаливым падением.

функці́ѧ Факторїа́лъ (н):
    а҆́ще н не вѧ́щше 1:
        возвратѝ 1
    возвратѝ н * Факторїа́лъ(н - 1)

функці́ѧ Фибона́ччи (н):
    а҆́ще н менѣ́е 3: возвратѝ 1
    возвратѝ Фибона́ччи(н - 1) + Фибона́ччи(н - 2)

глаго́ли «10! =», Факторїа́лъ(10)
для к во 10: рцы̀ к, Фибона́ччи(к)

9.4Вызов через точку

Запись х.дѣ́йство(…) означает то же, что дѣ́йство(х, …): значение перед точкой становится первым доводом. Это удобно для встроенных действий над свитками и словами:

свѣ́чи є҆́сть [«ꙋ҆ спа́са», «ꙋ҆ бг҃оро́дицы»]
свѣ́чи.приложи(«за ᲂу҆покое́нїе»)
глаго́ли свѣ́чи.длина(), «свѣ́чи:», свѣ́чи.совокупи(«; »)

Глава 10 і҃Свитки и словники

✦ ✦ ✦

Свиток хранит значения по порядку, словник — по ключам. Оба вида изменяемы: элементы можно заменять и добавлять. Элемент берётся словом ѿ («от») или квадратными скобками.

10.1Свитки

Счёт в свитках ведётся с единицы — как и в кириллической цифири, где нуля нет.

а҆збꙋ́ка є҆́сть [«а҆́зъ», «бꙋ́ки», «вѣ́ди»]
глаго́ли а҆збꙋ́ка ѿ а҃, а҆збꙋ́ка[3], длина(а҆збꙋ́ка)
а҆збꙋ́ка ѿ д҃ є҆́сть «глаго́ль»          # №4 = длина+1: добавить
приложи(а҆збꙋ́ка, «добро̀»)
глаго́ли а҆збꙋ́ка
глаго́ли «Изъя́то:», изъми(а҆збꙋ́ка), «ѡ҆ста́лось:», длина(а҆збꙋ́ка)
глаго́ли имать(а҆збꙋ́ка, «бꙋ́ки»), имать(а҆збꙋ́ка, «ꙋ҆́къ»)
Внимание

Обращение к несуществующему номеру — анафема: «указатель 0 внѣ свитка (длина 3). Помни: счётъ ѿ единицы, ибо нуля несть».

10.2Словники

Словник сопоставляет ключам значения. Ключами могут быть слова, числа и истинности. Обращение к отсутствующему ключу не ошибка: оно возвращает безвѣ́стно. Присваивание по новому ключу добавляет запись.

гла́съ є҆́сть {1: «Воскресе́нъ», 2: «Ѻ҆́тче на́шъ»}
гла́съ ѿ 3 є҆́сть «Бцⷣе дв҃о»
глаго́ли гла́съ
глаго́ли гла́съ ѿ 2, гла́съ ѿ 8
глаго́ли ключи(гла́съ), имать(гла́съ, 3), длина(гла́съ)
для к во гла́съ: глаго́ли «гла́съ», кириллицею(к), «—», гла́съ ѿ к

Глава 11 а҃іВвод и вывод

✦ ✦ ✦

Программа общается с человеком через консоль: печатает словом глаго́ли и спрашивает действием внемлѝ(). Вся кириллица, включая надстрочные знаки, выводится и читается правильно.

11.1глаго́ли

Вычисляет все перечисленные выражения слева направо и печатает их значения через пробел, затем переводит строку. глаго́ли без доводов печатает пустую строку. Слова печатаются как есть, свитки и словники — в квадратных и фигурных скобках, логические значения — словами и҆сти́на и ло́жь.

11.2внемлѝ

внемлѝ() читает строку с клавиатуры и возвращает её как слово. Если передать довод, он будет напечатан как приглашение (без перевода строки). Чтобы получить число, оберните результат в число():

а є҆́сть число(внемлѝ(«Пе́рвое число̀: »))
б є҆́сть число(внемлѝ(«Второ́е число̀: »))
глаго́ли «Сꙋ́мма:», а + б, «=», кириллицею(а + б)

Глава 12 в҃іПрегрешения и анафема

✦ ✦ ✦

Ошибки бывают двух родов. Прегрешение — ошибка в тексте программы: транслятор находит её до компиляции и указывает строку и столбец. Анафема — ошибка во время выполнения: программа сообщает, что случилось и в какой строке, и завершается с кодом 1.

12.1Прегрешения

Прегрешение выводится в формате файл:строка:столбец: прегрѣшеніе: описание. «Скрипторїй» подчёркивает ошибочное место волнистой линией прямо во время набора.

а є҆́сть 1
глаго́ли а + б
а҆́ще и҆сти́на:
глаго́ли «забы́лъ ѿстꙋ́пъ»

12.2Анафема

глаго́ли «До дѣле́нїѧ»
х є҆́сть 10 / 0
глаго́ли «Сего̀ не ᲂу҆ви́димъ»

Программа может предать анафеме сама себя, если обнаружит недопустимое положение:

покло́ны є҆́сть 99
а҆́ще покло́ны вѧ́щше 40:
    анаѳе́ма «Не прели́стисѧ: сꙋ́гꙋбїе ᲂу҆се́рдїѧ є҆́сть пре́лесть»
глаго́ли покло́ны

12.3Коды завершения

КодКогда
0программа дошла до конца или выполнила возвратѝ в главном теле без значения
нвозвратѝ н в главном теле, где н — целое

Глава 14 д҃іПримеры программ

✦ ✦ ✦

Несколько законченных программ, которые показывают язык в деле. Все они есть в папке examples\Адонаи.

14.1Пасхалия

Вычисление дня православной Пасхи по формуле Гаусса для юлианского календаря с переводом на гражданский стиль. Программа использует словники, функцию, возвращающую свиток, и обход чреды лет.

# Пасха́лїѧ: дни́ пра́вославныѧ Па́схи (вѣ́рно для 1900–2099 лѣ́тъ).
мѣ́сѧцы є҆́сть {3: «ма́рта», 4: «апрѣ́лѧ», 5: «ма́ѧ»}
дни̑ є҆́сть {3: 31, 4: 30, 5: 31}

функці́ѧ Па́сха (лѣ́то):
    а є҆́сть лѣ́то % 4
    б є҆́сть лѣ́то % 7
    в є҆́сть лѣ́то % 19
    д є҆́сть (19 * в + 15) % 30
    е є҆́сть (2 * а + 4 * б - д + 34) % 7
    мѣ́сѧцъ є҆́сть (д + е + 114) // 31
    де́нь є҆́сть (д + е + 114) % 31 + 1 + 13   # ю҆лїа́нскїй → гражда́нскїй

Приложение АГрамматика

✦ ✦ ✦

Ниже — грамматика языка в расширенной форме Бэкуса — Наура. Ключевые слова даны в нормализованном виде (глава 3), NEWLINE, INDENT и DEDENT — конец строки, увеличение и уменьшение отступа.

программа    = { предложение } ;
предложение  = функция | условие | цикл_пока | цикл_для | простое NEWLINE ;
блок         = ":" ( простое NEWLINE | NEWLINE INDENT { предложение } DEDENT ) ;

функция      = "функция" ИМЯ "(" [ довод { "," довод } ] ")" блок ;
довод        = ИМЯ [ ( "есть" | "=" ) простое_значение ] ;
условие      = "аще" выражение блок { "иначе" "аще" выражение блок } [ "иначе" блок ] ;
цикл_пока    = "покуда" выражение блок ;
цикл_для     = "для" ИМЯ "во" выражение блок ;

простое      = "возврати" [ выражение ] | "прерви" | "продолжи"
             | "глаголи" [ выражение { "," выражение } ] | "анафема" выражение
             | ИМЯ { "," ИМЯ } ( "суть" | "же" ) ВИД
             | цель ( "есть" | "бысть" | "=" | "+=" | "-=" ) выражение
             | выражение ;
цель         = ИМЯ | постфикс ( "от" первичное | "[" выражение "]" ) ;

выражение    = и_выр { ( "або" | "или" | "либо" ) и_выр } ;
и_выр        = не_выр { "и" не_выр } ;
не_выр       = "не" не_выр | сравнение ;
сравнение    = сумма [ { "не" } [ "есть" ] { "не" } ( "вяще" | "менее" ) сумма
                     | { "не" } "есть" { "не" } сумма
                     | ( "==" | "!=" | "<" | ">" | "<=" | ">=" ) сумма ] ;
сумма        = произв { ( "+" | "-" ) произв } ;
произв       = унарное { ( "*" | "/" | "//" | "%" ) унарное } ;
унарное      = ( "-" | "+" ) унарное | постфикс ;
постфикс     = первичное { "(" доводы ")" | "[" выражение "]"
                         | "от" первичное | "." ИМЯ "(" доводы ")" } ;
первичное    = ЧИСЛО | СЛОВО | "истина" | "ложь" | "безвестно" | ИМЯ
             | "(" выражение ")" | "[" доводы "]" | "{" [ пара { "," пара } ] "}" ;
пара         = выражение ":" выражение ;
